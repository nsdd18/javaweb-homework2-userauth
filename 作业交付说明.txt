【六、关键验证结论】
------------------------------------------------------------
    · MySQL 8.0.12 服务运行中，数据库 javaweb_homework、表 user 存在
    · user 表 8 个字段，username 唯一索引，字符集 utf8mb4
    · 通过页面注册后，user 表新增一条记录（含 create_time / update_time）
    · password 字段为 64 位十六进制（SHA-256），salt 字段 32 位（16 字节盐）
    · 直接用明文密码查询 password 字段，命中 0 条 —— 库中无明文密码
    · 忘记密码重置后 update_time 变化，新密码可登录、旧密码失效
